# Sample Library Reference Manual

Autogenerated API and CLI specification for `audio-dsp-toolkit`.

## Capability Index

### `normalize-audio`
- **Symbol**: `normalize_audio`
- **Summary**: Normalizes floating-point audio sample array to target decibel ceiling.
- **Returns**: `List`
- **Parameters**:
  - `samples` (List): Array of raw floating point audio samples between -1.0 and 1.0.
  - `target_db` (number): Target peak volume level in decibels.
  - `peak_limit` (number): Hard ceiling limit to avoid digital clipping distortion.

### `apply-bandpass-filter`
- **Symbol**: `apply_bandpass_filter`
- **Summary**: Applies Butterworth bandpass frequency filter across sample stream.
- **Returns**: `List`
- **Parameters**:
  - `samples` (List): Time-domain audio sample stream.
  - `low_cutoff_hz` (integer): Lower frequency threshold in Hertz.
  - `high_cutoff_hz` (integer): Upper frequency threshold in Hertz.
  - `order` (integer): Filter slope order roll-off steepness.

### `create-spectrumanalyzer`
- **Symbol**: `SpectrumAnalyzer.__init__`
- **Summary**: Instantiates SpectrumAnalyzer. Computes Fourier frequency spectra and harmonic distortion metrics.
- **Returns**: `Any`
- **Parameters**:
  - `sample_rate` (integer): Audio sampling frequency in Hertz.
  - `fft_size` (integer): Fast Fourier Transform window bin size.

### `compute-energy-bins`
- **Symbol**: `SpectrumAnalyzer.compute_energy_bins`
- **Summary**: Calculates energy density per standard octaval frequency band.
- **Returns**: `Dict`
- **Parameters**:
  - `samples` (List): Audio window to analyze.
